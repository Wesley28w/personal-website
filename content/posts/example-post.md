This is an example blog post written in **Markdown**. You can use all the usual formatting.

## Subheadings work

So do lists:

- First item

### Code blocks

```python
def hello():
    print("Hello, world!")
```

Inline code works too: `const x = 42`.

### Math with LaTeX

Inline math: $E = mc^2$

Display math:

$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$

Embed a YouTube video with plain HTML inside your markdown:

<iframe width="100%" height="360" src="https://www.youtube.com/embed/dQw4w9WgXcQ" frameborder="0" allowfullscreen></iframe>

Or a local video:

</video>
